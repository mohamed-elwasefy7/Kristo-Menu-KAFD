## ⭐ التحديث اليومي (الفطور + أطباق اليوم)

كل اللي بتعمله: تعدّل ملف `daily.js` — اسم عربي + اسم إنجليزي + سعر. من غير صور.

### من الموبايل أو المتصفح (الأسهل):
1. افتح الريبو: `github.com/mohamed-elwasefy7/Kristo-Menu-KAFD`
2. دوس على ملف **`daily.js`**
3. دوس زرار القلم ✏️ (**Edit**)
4. عدّل الأصناف — كل صنف سطر واحد بالشكل ده:
   ```js
   { ar: "مكرونة بشاميل", en: "Pasta Bechamel", price: 29 },
   ```
5. دوس **Commit changes** (مرتين)
6. خلاص ✅ — الموقع بيتحدث لوحده خلال دقيقة تقريباً.

### قواعد بسيطة:
- النصوص بين علامات تنصيص `"..."` والسعر رقم من غير تنصيص.
- كل صنف ينتهي بفاصلة `,`
- مفيش أصناف النهارده؟ سيب القوسين فاضيين: `dishes: [],` → هيظهر كارت "اسأل الكاشير" أنيق بدل القسم الفاضي.

## تفعيل النشر أول مرة (خطوة واحدة — مرة واحدة بس)

1. افتح الريبو → **Settings** → **Pages** (من القائمة الشمال)
2. تحت *Branch*: اختار **main** و **/(root)** → **Save**
3. استنى دقيقة — الرابط فوق يشتغل. ✅

## طباعة QR للطاولات

افتح `qr.html` في المتصفح (أو من الرابط: `/qr.html`) → الرابط الحقيقي محطوط جاهز → **طباعة**.
