# كريستو / Cristo — المنيو الرقمي (فرع كافد)

منيو رقمي للزباين، ثنائي اللغة (عربي/إنجليزي)، يُفتح من QR كود. عرض فقط — بدون طلبات.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | المنيو نفسه — ملف واحد كامل (HTML+CSS+JS، البيانات مدمجة). |
| `menu.json` | بيانات المنيو (137 صنف / 10 أقسام) — عدّل الأسعار أو الأسماء من هنا. |
| `qr.html` | صفحة توليد QR كود جاهزة للطباعة (تفتحها في المتصفح). |
| `images/` | صور الأصناف (21 صورة). |

> **مهم:** لو عدّلت `menu.json`، لازم تُعيد حقن بياناته داخل `index.html` (البيانات مدمجة، مش مقروءة من الملف). قوللي وأعيد البناء.

## طباعة بطاقة الـQR

1. افتح `qr.html` في المتصفح — الرابط الحقيقي محطوط جاهز.
2. اضغط **تحديث الكود** ← **طباعة**.
3. اطبع البطاقة وحطها على الطاولات. ✅
